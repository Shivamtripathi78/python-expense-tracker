# 💰 Python Expense Tracker

A simple, command-line expense tracker built with Python to help users record expenses, monitor spending, and organize their finances.

## ✨ Features

- Add expenses with amounts, categories, and descriptions.
- View all recorded expenses.
- Calculate total spending.
- Generate category-wise spending summaries.
- Automatically save expenses in a JSON file.
- Validate user input and handle common errors.

## 🛠️ Technologies Used

- Python 3
- JSON for data storage
- Python standard library
